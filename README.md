# Superwhisper

Recreation of [superwhisper.com](https://superwhisper.com) — AI voice-to-text for macOS, Windows, and iOS.

## Stack

React 19, TypeScript, Vite, TanStack Start, Tailwind CSS v4.

## Scripts

```bash
npm install
npm run dev      # http://localhost:8080
npm run build
npm run typecheck
```

## Pages

- `/` — marketing landing page
- `/pricing` — pricing
- `/docs/*` — documentation (search ⌘K, assistant ⌘I)
- `/login` — sign in
